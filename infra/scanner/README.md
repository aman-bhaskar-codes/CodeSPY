# Offline source scanner image

This image contains Semgrep CE 1.179.0, Gitleaks 8.30.1 and CodeSPY-authored rules. It is an unqualified development image until owned Linux integration checks pass. The application does not enable scanning merely because this Dockerfile exists.

Build with an explicit disposable context containing only regular Python files from `backend/app`, the Dockerfile, runtime layout, hashed requirements, build scripts and authored rules from this directory, preserving their relative paths. Never send the whole checkout as a build context: it may contain private local files. Dependency installation occurs only while building this trusted image, using exact versions and hashes. The build-only downloader verifies the Linux Gitleaks release archive before reading its executable member. Uploaded packages are never installed.

The entrypoint accepts a bounded `/input/request.json` alongside the original admitted archive and manifest, mounted individually read-only. It authenticates those objects under the original admission policy, verifies persisted file identities and selected UTF-8 bytes, then stages generated UUID aliases in private tmpfs. Native commands receive generated names and authored rule files only. Raw native reports remain private process memory. Stdout contains a metadata-only `ScannerResultV1`; native stderr is discarded after enforcing its byte limit. Result locations use original UTF-8 byte ranges. Gitleaks format matches are not active-key verification, and source pattern matches are review candidates rather than exploit proof.

Required host controls are a pinned local image ID, nonroot user, read-only root and inputs, no network, no capabilities, no-new-privileges, 1 GiB memory/swap, two CPUs, 64 PIDs, bounded private tmpfs, no persistent Docker logging, an aggregate 180-second deadline, and exact durable container ownership/cleanup. The container entrypoint alone does not establish these controls. Broker integration and actual Linux qualification remain required.

The Semgrep profile supports explicit Python subprocess `shell=True` and selected requests calls with `verify=False`. It does not establish attacker-controlled flow, binding completeness or reachability. The Gitleaks profile checks only the classic GitHub PAT-like format, with archive/decode traversal and target suppression disabled. It does not run the bundled default rule catalog.

Engine and rule licensing are separate. Semgrep's source license is [LGPL 2.1](https://github.com/semgrep/semgrep/blob/v1.179.0/LICENSE); Gitleaks is [MIT](https://github.com/gitleaks/gitleaks/blob/v8.30.1/LICENSE). Rules in this directory are authored for CodeSPY and distributed under the repository license; no Semgrep Registry rules are bundled. Retain package license metadata and Gitleaks notices in distributed images.

The runtime layout is selected in `runtime-layout.json` during trusted composition. The build captures artifact/rule digests in a readonly runtime manifest; native adapters consume that manifest rather than choosing executable or rule paths from a request. Dependency resolution uses the recorded publication cutoff. The declared MCP 1.29.0 dependency has GHSA-84m7-p3x7-pcfv, affecting stateful Streamable HTTP servers. This image is restricted to fixed CLI scanning without MCP server mode or network access; that exception requires containment qualification and is not a clean dependency-audit claim.
